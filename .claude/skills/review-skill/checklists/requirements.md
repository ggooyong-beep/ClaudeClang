# 요구사항 리뷰 체크리스트 (SWE.1)

| # | 항목 | 결과 | 근거 |
|---|---|---|---|
| R1 | 모든 요구사항이 기능/비기능(품질·제한·제약)으로 분류됨 | | |
| R2 | 기능 안전 요구사항이 별도 문서로 분리됨 | | |
| R3 | 품질 요구사항이 ISO 25010 특성에 매핑됨 | | |
| R4 | 각 요구사항이 원자적이며 모호어가 없음 | | |
| R5 | 각 요구사항에 검증 방법이 있고 측정 가능함 | | |
| R6 | ID가 유일하고 규칙을 따름 | | |
| R7 | 상위 요구와의 추적이 100% (누락·고아 없음) | | |
| R8 | 요구사항 간 충돌·중복이 없음 | | |
| R9 | 미확정 값이 open issue로 관리됨(임의 가정 없음) | | |
