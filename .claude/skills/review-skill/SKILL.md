# Review-Skill

## 규칙
1. **모든 산출물**은 이 스킬로 리뷰한다. 매 단계가 끝날 때마다 수행하며, 리뷰 통과 전에는 다음 단계로 넘어가지 않는다.
2. 리뷰는 **산출물별 체크리스트**(`checklists/`)를 기반으로 항목마다 Pass/Fail/N-A와 근거를 기록한다. 체크리스트에 없는 결함을 발견하면 리뷰어는 항목을 추가한다(체크리스트 개발·유지).
3. 작성자와 리뷰어는 분리한다. 리뷰는 별도 서브에이전트(`reviewer`)가 수행한다.
4. Fail은 결함 목록(ID, 심각도, 위치, 수정 요구)으로 작성자에게 돌려주고, 수정 후 해당 항목을 **재리뷰**한다. 모든 항목이 Pass/N-A가 되어야 종료한다.
5. 정량 기준은 말로 판단하지 않고 도구 결과를 근거로 한다(순환복잡도, CppCheck, 커버리지 리포트 등).

## 리뷰 기록 (`docs/reviews/<산출물>-review-<날짜>.md`)
대상 산출물·버전, 리뷰어, 체크리스트 항목별 결과표, 결함 목록, 결론(승인 / 조건부 승인 / 반려), 재리뷰 이력.
